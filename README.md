# 🚀 UniSync: The Ultimate Campus Utility & Feedback Hub

**UniSync** is a robust full-stack ecosystem designed to digitize and streamline the student experience. It serves as a unified bridge between the campus community and administration, combining real-time feedback with essential utility modules like event registration, academic resource sharing, and secure payments.

## ✨ Key Modules & Features

### 👤 1. Advanced Student Profile & Stats
A personalized dashboard for every user to track their campus activity.
* **Activity Tracking:** Displays real-time counts of **Notes Uploaded** and **Events Registered**.
* **Identity Management:** Managed via secure JWT authentication for personalized data access.

### 📚 2. Academic Notes Hub (Full CRUD)
A collaborative space for sharing study materials.
* **Complete Control:** Users can **Upload (Create)**, **View (Read)**, **Modify (Update)**, and **Remove (Delete)** their own study notes.
* **Organization:** Categorized resources for easy navigation and subject-wise access.

### 📅 3. Event Management & Secure Payments
Seamlessly browse and join campus activities.
* **Event Registration:** View upcoming workshops, fests, and seminars with instant enrollment.
* **Integrated Payments:** Secure financial transactions for paid events with real-time feedback.

### 💬 4. Dynamic Review System
A transparent platform for campus facility and academic feedback.
* **Full CRUD Lifecycle:** Write reviews and maintain the ability to **Edit** or **Delete** your own feedback.
* **Smart Recognition:** Automated "You" badges identify personal reviews for better tracking.

### 🌓 5. Global Dark Theme Sync
A premium, eye-friendly user experience powered by JavaScript.
* **Persistent Theme:** Integrated with `localStorage` so the "Moon Icon" toggle remembers your preference across all pages.
* **Modern Aesthetic:** Instantly swaps CSS variables for a high-contrast dark look across the entire site.

### 📞 6. Contact & Inquiry Portal
* **Inquiry Form:** A dedicated channel for students to send formal queries.
* **Official Directory:** Verified email and phone contact details provided for immediate campus assistance.
